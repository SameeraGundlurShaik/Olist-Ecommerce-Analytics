# Olist E-Commerce Analytics

## Project Overview
An end-to-end data analytics project using the Brazilian E-Commerce Public Dataset by Olist. The project explores sales performance, product categories, payment methods, delivery performance, and customer reviews.

## Tools & Technologies
- **Python:** Pandas, data profiling, and data cleaning
- **MySQL:** Database creation and data validation
- **SQL:** Joins, aggregations, and business analysis
- **Power BI:** Data modeling, DAX measures, KPI cards, and interactive visualizations

## Project Workflow
1. Profiled the datasets and examined data quality.
2. Cleaned datasets using Python and Pandas.
3. Loaded data into MySQL tables.
4. Performed data validation and SQL analysis.
5. Built an interactive Power BI dashboard.
